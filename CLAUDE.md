# CLAUDE.md

Guidance for AI agents working in this repository.

## Commits

- Write commit messages in English.
- Follow Conventional Commits: `<type>: <short summary>` (`feat`, `fix`, `chore`, `style`, `refactor`, `docs`, `test`, `perf`), imperative mood, no period at the end.
- Keep the subject line short; add a body only when the "why" isn't obvious from the diff.
